# Subsystem contracts and failure modes

These contracts precede claims about completeness. Public methods are deliberately narrow; the implementation status is in `status.md`.

| Subsystem | Input / output contract | Failure behavior | Acceptance evidence |
|---|---|---|---|
| **Warp** | Immutable `DecisionRequest` + `CompiledPolicy` → verdict, canonical Thread record, optional Quanta lease. Independent authority indexes compose by compiled rank. | Invalid/unavailable policy is rejected before serving; no match denies; guard miss abstains; budget reserve failure denies without fallback. | `WarpHeddleThreadTest`, `GenerativeLawsTest`; branch report in CI. |
| **Heddle** | Strict UTF-8 JSON v1 → typed role/rule graph, diagnostics, immutable indexes. Unknown fields are errors. | Unsupported schema, ambiguous semantics, invalid pattern, role cycle, invalid override, or unproven ceiling coverage fail compilation. No best-effort repair. | Compiler negative tests, starter-pack CLI test, JSON schema. |
| **Thread** | Deterministic record → public/staff/audit renderings; signed link claims bind record digest, subject, disclosure scope, and expiry. | Bad MAC, expiry, subject mismatch, or over-broad disclosure fails closed. Public rendering omits IDs, rule names, and audit trace. | Public leakage assertions, byte-stable record test, token tampering/scope/expiry tests. |
| **Selvedge** | Compiled mutation rules inspect every authorization request before policy indexes. | Self-grant without a distinct actor/target and dynamic ceiling mutation are denied at invariant precedence. Approval split requires different stable IDs. | Invariant path tests. This is not yet a complete exploit catalogue. |
| **Skein** | Ordered mutations → hash-chained encrypted events; checkpoints accelerate reconstruction; decision journal is separate and sampled/filtered. | Hash/checkpoint mismatch throws; destroyed subject key yields an explicit erased value while hashes remain verifiable. | In-memory chain, reconstruction, and crypto-shred tests. **Not crash durable yet.** |
| **Weft** | HLC-stamped mutations → deterministic merged snapshot or local quarantine. Duplicate identical IDs are idempotent; conflicting IDs quarantine. | Failed invariant returns the original local snapshot and an alert. Revocation needs an explicit approved regrant to reverse. | Clock-skew, duplicate, order, quarantine, and bound-measurement tests. **No network transport or demonstrated 2-second SLA yet.** |
| **Ply** | Stable Java UUID / Bedrock XUID / service identity → one immutable subject and alias/name history. | Ambiguous alias, unverified cross-platform link, or display-name lookup cannot create an authorization binding. Offline-mode identities are risk-labelled. | Rename stability, name lookup rejection, cross-identity proof tests. **No authentication provider is included.** |
| **Tessellation** | Immutable world/region polygon snapshot → sorted containing regions using world, cell, bounds, and point-in-polygon rejects. | Non-finite coordinates, invalid polygon, or invalid snapshot config are rejected. | Boundary, overlap, world isolation, and cache immutability tests. **No server-thread integration or production-scale benchmark yet.** |
| **Quanta** | Budget class + stable subject + scope + spec → synchronized atomic lease or retry duration. | Spec changes under the same budget key fail; exhausted reservation denies. Lease commit/release is idempotent and mutually exclusive. | Concurrent capacity, refund, and conservation tests. |
| **Sigil** | Signed claims → fast local verification of holder/audience/scope/expiry/revocation; delegation must be a subset and not outlive its parent. | Signature, audience, scope, expiry, revocation, or delegation failure throws. | Tamper, scope, expiry, revocation, and delegation tests. **Revocation is process-local until a durable shared revocation feed exists.** |
| **Vigil** | Attributed grant/revoke events → explainable alerts and actor freeze. Compliance baseline precedes heuristics. | Baseline violation and high-severity heuristics freeze; dismissal/unfreeze requires an auditable reason. | Rule-based trigger and dismissal tests. **No statistical/AI behavior is present.** |
| **Loom** | Human question / graph selection → readable evidence interaction. Keyboard focus, labels, and text severity survive without color. | Disconnected prototype labels itself; it must not imply live data, signed links, or applied changes. | Static manual acceptance checklist; current page explicitly labels sample data. **Not wired to APIs.** |
| **Replay** | Recorded request corpus + candidate engine → verdict differences, transitions, stable affected subjects, explanation-only count. | Candidate run must use isolated budget state. Cutover is eligible only at zero verdict divergence or explicit acceptance. | Verdict-diff and gate tests. **No production traffic capture/canary controller yet.** |
| **Beacon** | Bounded metric series and registered health checks → snapshots and dated doctor report. | Series overflow is explicit; a thrown check becomes a FAIL result. | Metric bounds and doctor failure tests. |
| **Bastion** | Admin-authorized plugin registration + key + action → attributed principal under mutation scopes and API budget. | Unregistered key, missing write scope, invalid rate, or unauthorized registration rejects. | Rogue registration, scope, authentication, and rate-limit tests. **No network middleware or key rotation service yet.** |
| **Palette** | Versioned policy packs with tests and guided first-run. | Pack is copied, not applied; lint/review is required before live use. | Survival pack compile and CLI init/lint tests. Other packs are not shipped. |
| **Shuttle** | Legacy entries → candidate diff plus semantic gaps; never writes active policy. | Mutable principal, unsupported node, wildcard mismatch, and unsupported context are review findings. | Review-only importer test. **Major-product importers/exporters are not complete.** |
| **Bridge** | Stable identity + pre-captured context → compatibility verdict; bulk checks preserve per-request evidence. Observers are non-authoritative. | Request-template identity mismatch fails; observer extensions cannot grant. | Bulk and observer tests. **No Bukkit/Paper/Fabric/Velocity adapter, annotation processor, or verified zero-allocation fast path yet.** |

## Cross-cutting failure policy

- Compilation errors are fatal before a candidate can enter an index.
- A missing state source, context field, budget bucket, token, or identity binding must not create an allow.
- Network-facing behavior is not considered complete until authentication, bounded rate, quarantine telemetry, and chaos evidence exist.
- Prototype data is never represented as server truth. The static Loom screen and CLI demo say so in the interface.
